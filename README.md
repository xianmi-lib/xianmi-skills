# xianmi-skills

[Agent Skills](https://agentskills.io) for **Xianmi Library** ([显密文库](https://www.xianmi.co/)) — a non-profit digital library of Chinese Buddhist texts (sutras 佛经, commentaries 注疏, Chinese/Tibetan/Theravada traditions, modern Chinese translations of the canon).

## Skills

- [`xianmi-library`](skills/xianmi-library/SKILL.md) — search and read the library via its MCP server (`https://mcp.xianmi.co/mcp`) or its plain HTTP/Markdown interfaces. Covers tool selection, the parallel 简体/繁體 editions, citation and licensing rules, and verse-anchor (`<!-- verse:* -->`) semantics.

## Usage

Copy `skills/xianmi-library/` into your agent's skills directory, or point your agent tooling at this repository. The skill follows the [Agent Skills specification](https://agentskills.io/specification).

中文說明見站內[《AI 接入指南》](https://www.xianmi.co/for-ai/)（[简体版](https://www.xianmi.co/for-ai/) · [正體版](https://www.xianmi.co/zh-tw/for-ai/)）。
